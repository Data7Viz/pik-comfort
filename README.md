# С чего всё началось.
### А началось вот с чего.

Изучал CAN J1939 через написание своих утилит. Пишу на Си. В первую очередь нужно раскавырять структуру, потом пишешь программу. 

- Структура лога J1939
- time -> id -> data
- на этот раз взрывал могзи в time (1782249168.279401) 

### И тут бытовая проблемка со стороны Управляющей Компании

- **1** Услуга "Телетрансляция" отключена **НО** оплата всеровно приходит
- **2** Замена счётчика ГВС по гарантии. 
- **3** Содержание Общедомового Имущества по двойному тарифу. В том числе и Телетрансляция которая отключена.
- ** Я в этих вопросах полный ноль**
